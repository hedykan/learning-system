# 开发计划

开发计划只描述如何交付已进入 `spec/versions/` 的需求，不创造新需求。发现需求缺口时停止扩展实现，先进入 `spec/ideas.md` 或建立变更单。

下一版本：[v0.1.9 基线](../spec/versions/v0.1.9.md)（尚未开始），其后 [v0.2 草案](../spec/versions/v0.2.md)。已完成：[v0.1.8](./v0.1.8/README.md)、[v0.1.7](./v0.1.7/README.md)、[v0.1.6](./v0.1.6/README.md)、[v0.1.5](./v0.1.5/README.md)、[v0.1.4](./v0.1.4/README.md)、[v0.1.3](./v0.1.3/README.md)。v0.1.2 仅剩真实 Vault 回填（[计划](./v0.1.2/README.md)）。已完成计划：[v0.1.1](./v0.1.1/README.md)、[v0.1](./v0.1/README.md)。

每个阶段依次经历：测试场景 → 最小实现 → 重构 → 文档同步 → 阶段验收。阶段状态只允许 `not-started`、`in-progress`、`done`、`blocked`。
