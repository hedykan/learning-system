## 真实 Agent 复验（2026-09-28，Codex gpt-5.6-sol 低思考，4 轮）

场景：陈纪修《数学分析》，Markdown 讲义为主资料，B 站第 3 讲为外部资料。

| 检查 | 结果 |
| --- | --- |
| 外部资料 | Agent 用 `source add --external` 登记第 3 讲；大纲未确认时挂载被拒，Agent 先请学习者确认目录，确认后挂到 1.1（`3/05:20-48:00`） |
| 资料输出 | `status` 的 `node_resources` 与教材首页列出“第 3 讲 05:20–48:00” |
| 读原文 | 讲解前用 `learn source read` 按锚点读讲义（第 3 轮） |
| 数学公式 | 4 轮回复无 LaTeX 源码，量词与推导全部用 ∀、∃、ε、aₙ；出现 2 次 `a_N`，已补充规则 |
| 学习事件 | 量词顺序误解 → 修正 → 应用；有界性为 insight；学习者问题成为问题对象 |
| 关系类型 | Agent 使用了 `contrast` 类型 |
| 图谱 | 默认 `graph.json` 已写入；概念、问题、总览、进度、Session、原始对话均带层级标签；每个概念笔记只有 1 个原始对话链接 |
| 流程 | 结束时位置推进到 1.2；`next` 为 learn 阶段；沙箱内提交失败，结束语提示 `learn commit` |

遗留观察：

- 教材要点仍未提交（IDEA-027）。

- Agent 导入时未给 `--title`，教材名显示为文件名 `limits`。
