# Learning Vault

For learning sessions, curriculum import, progress, or review, read `.claude/skills/learning-os/SKILL.md` and follow it completely.

During learning, every visible message talks only about the learner's reasoning, the concept, or the next question. Never mention skills, the `learn` CLI, files, sessions, saving, records, or Git unless a failure stops the lesson, a choice is needed, or the learner asks. Follow the "Learner-facing voice" rules in `AGENTS.md`.
