# 变更摘要

讲过但没有完成的目录条目显示为“学过一部分”，不再误显示为“未开始”或“未覆盖”；笔记里每条学习者原话显示这一轮对话的实际时间，而不是 Session 开始时间。

## 动机

2026-09-26 的 v0.1.3 实测中，Codex 在 2.3“可靠性与容错”讲了一题后回到 2.1 补学。2.3 已有学习证据和一个概念，教材首页却显示“○ 未开始”。同时，概念笔记中所有原话都标注为“2026-09-24 09:02”，这是 Session 开始时间，实际对话发生在 09:45 或第二天，容易误读。

## 目标行为

### 学过一部分

- 新增条目状态 `partial`（“◐ 学过一部分”），满足以下任一条件且未被完成或跳过、也不是当前位置时成立：
  - `progress.yaml` 中有 Session 在该条目结束的记录；
  - 有 Concept 的 `source_ref.node` 指向该条目，且该 Concept 有学习证据。
- `partial` 优先于 `uncovered` 与 `not_started`。
- `status --json` 新增 `partial` 列表；教材首页与 `progress.md` 显示该状态。
- Skill 在开场处理未覆盖条目时，同时提醒学过一部分的条目，询问继续完成还是标记完成或跳过。
- `learn next` 的 R6 在推进时优先返回当前位置之前的 `partial` 条目，而不是直接给出下一个新条目。

### 原话时间

- 投影中每条证据的时间标签取该轮对话的时间戳，格式 `YYYY-MM-DD HH:MM · tNNNN`，按学习者所在时区（系统本地时区）显示。
- Session 链接仍显示 Session 开始时间，二者在文字上区分为“对话时间”和“Session”。

## 数据与兼容性影响

只改变派生状态与投影，不改变任何存储格式。

## 验收条件

1. 讲过一题后离开的条目显示为“学过一部分”，完成后变为“已完成”。
2. 位置之前、只有部分证据的条目不出现在 `uncovered`，而出现在 `partial`。
3. `learn next` 在 R6 时先返回位置之前的 `partial` 条目。
4. 同一 Session 中两次不同时间的原话，在笔记中显示各自的时间。
5. 重建投影逐字一致。

## 决策

2026-09-26 接受，进入 v0.1.4。
