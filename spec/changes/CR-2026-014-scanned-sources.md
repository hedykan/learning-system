# 变更摘要

不在程序中实现 OCR。Agent 发现教材页面提取不出文字时，先用自身的视觉能力读取页面图像；仍无法可靠读出时，明确告诉学习者并建议换用文字版，绝不凭记忆教学。

## 目标行为

- Skill 规定读取顺序：文字提取；失败时把该页渲染为图像，用模型视觉读取；仍不可靠时停止并告知学习者。
- 用视觉读出的目录与要点，在目录确认前向学习者说明“这是从扫描页识别的，请核对”。
- 渲染出的图像只放在 `.learning/tmp/`。
- 程序保持多平台，不依赖任何平台 OCR 框架。

## 验收条件

1. Skill 的目录、原文教学与教材要点流程都包含上述顺序。
2. 自动化测试确认生成的 Skill 含有换用文字版的指引。

## 决策

2026-09-26 接受，进入 v0.1.5。
