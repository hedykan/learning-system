# 变更摘要

`curriculum complete` 或 `skip` 标记的正是当前位置所在条目时，程序自动把位置移到目录中下一个未完成的条目。

## 动机

v0.1.5 场景 14 部分通过：Agent 完成 2.1 后没有移动位置就开始讲 2.2，绕行时记下的返回点因此错成 2.1；全书学完时位置也停在 3.1 而不是 3.2。

## 目标行为

- 标记的条目等于当前位置 node，且不在 Detour 中时，位置移到 `NextNode`，当前概念清空；输出与 JSON 中报告 `moved_to`。
- 没有下一个条目（全书完成）时位置保持不变。
- 标记其他条目时不移动位置。

## 验收条件

1. 完成当前条目后位置自动到下一条目；完成非当前条目时位置不变。
2. Detour 期间不自动移动。
3. 全书最后一节完成后位置停在最后一节。

## 决策

2026-09-28 接受，进入 v0.1.6。
