# 变更摘要

为 Vault 增加界面语言设置。程序生成的固定文字（页面名、小标题、状态文字、首页与总览说明、Session 标题）按设置的语言输出；先支持中文与英文，其他语言回退到英文。Agent 写的内容（概念名称、问题、解释、原话）本来就跟随学习者语言，不受影响。

## 动机

v0.1.6 起笔记以概念名称命名，但固定文字仍写死为中文。英文或法文学习者会看到英文或法文的概念名配上中文的小标题、状态与页面名，中外文混杂。

## 目标行为

- `.learning/config.yaml` 新增 `language`，取值 `zh` 或 `en`；缺省为 `zh`，与现有 Vault 行为一致。
- `learn init --language <zh|en>`；`learn config set language <zh|en>` 修改后自动重建投影。
- Agent 在 `learn init` 或第一次学习时，根据学习者对话所用语言设置；学习者要求换语言时改设置。
- 固定页面名随语言切换，例如 `学习者总览.md` ↔ `Learner overview.md`、`学习进度.md` ↔ `Progress.md`；切换后沿用现有的旧命名迁移机制，手写区保留、旧文件删除。
- 所有固定文字集中在按语言分组的对照表中，新增语言只需补一份对照。
- 命令行输出保持英文，它只给 Agent 读。

## 验收条件

1. 设置 `en` 后重建，所有固定文字与固定页面名为英文，概念名称等 Agent 内容不变。
2. 从 `zh` 切到 `en` 再切回，手写区完整保留，没有残留的旧页面。
3. 缺省配置的 Vault 输出与 v0.1.6 完全一致。

## 决策

2026-09-28 接受，排入 v0.1.7。

2026-09-28 实现：固定文字对照表在 `internal/i18n`（中文原文为键，英文一张表）；策略理由也随语言输出。澄清：已有 Session 文件的标题保持创建时的语言，只有其解读区随语言重建，以免改写学习历史的外观。
