# 变更摘要

一门课程由“目标 + 已确认的大纲 + 挂在节点上的多份资料”组成。导入一本书只是“一份资料覆盖全部节点”的特例。

## 动机

实际学习常常混用资料：陈纪修《数学分析》是教材加视频课，DDIA 可以是书加补充论文，没有成型教材的方向要从多处拼起来（见 CR-2026-032）。现在一门课程只能对应一份资料。

## 目标行为

- `Curriculum/<id>/resources.yaml` 记录资料列表：`{id: r1, source: <Sources 下的资料>, role: primary|supplementary, title}`。
- 大纲节点可带 `resources: [{locator}]`，一个节点可挂多份资料的多个位置。
- `learn source attach <节点> <资料> <定位>` / `detach`；只能挂到已确认大纲上的节点，定位由对应适配器校验。
- 主资料（primary）至多一份；教材要点默认出自主资料，也可以用 locator 指向辅助资料。
- `learn next` 与 `status --json` 在当前节点下列出挂载的资料与定位，Agent 据此提示“这一节可以看第 3 讲 05:20–48:00”。
- 教材首页在每个节点下列出资料链接。

## 数据与兼容性影响

- 没有 `resources.yaml` 的旧课程视为只有一份主资料 `r1`，并隐式覆盖全部节点，不需要迁移。
- 归档与恢复（`curriculum remove/restore`）连同资料列表一起处理；被多门课程共用的资料只有在最后一门课程移除时才归档。

## 风险

- 资料多了之后，节点上的挂载难以维护。缓解：`learn source check` 报告无资料节点和失效定位。

## 验收条件

1. 旧课程不经迁移即可正常学习与重建。
2. 一个节点挂教材页码加视频时间点，`learn next` 同时列出二者。
3. 挂到未确认节点或定位非法时拒收。
4. 共用资料在其中一门课程移除后仍然可用。

## 决策

2026-09-28 接受，排入 v0.1.8。
