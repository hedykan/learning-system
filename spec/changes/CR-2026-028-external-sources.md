# 变更摘要

新增 `external` 资料：只记录名称、网址或出版信息，没有文件。目录由 Agent 根据播放列表、目录页照片或课程大纲建立，内容由学习者带进对话。用一个适配器覆盖所有“程序读不了”的资料。

## 动机

纸质书、视频课（如陈纪修《数学分析》）、线下课程现在都无法导入，因为 `curriculum add` 要求一个受支持的文件。其实系统的记录、复习、概念图谱都不依赖文件本身。

## 目标行为

- `learn source add --external --title <名称> [--url <网址>] [--note <出版信息>]`；也可以 `learn curriculum add --external ...` 直接建立只有外部资料的课程。
- 能力：`External: true`，其余为假。`source read` 返回 `unsupported`，原因为“外部资料，请学习者提供内容”。
- 定位允许 `page`、`time`、`text`；只校验格式，不校验存在性。
- 大纲仍需 Agent 草拟、学习者确认后才生效。
- Skill：
  - 视频：看之前先让学习者预测，看完先让学习者复述，再练习；学习者说“看完第 3 讲”时按挂载的定位判断完成哪个节点。
  - 纸质书：请学习者拍目录页建大纲；讲解依据学习者拍的页面或口述。
  - 不下载视频，不保存视频文件。

## 数据与兼容性影响

纯新增。`Sources/<id>/` 下只有 `source.yaml` 元数据。

## 风险

- 没有原文，Agent 可能凭记忆“讲教材”。缓解：Skill 要求没有学习者提供的内容时明确说“这部分是一般讲法，不一定和你的教材一致”，教材要点只能在学习者提供页面后提交。

## 验收条件

1. 能建立只有外部资料的课程并确认大纲、开始学习、完成节点。
2. `source read` 对外部资料返回 `unsupported` 与原因。
3. 一门“教材 PDF + 外部视频”的课程，节点同时挂页码和时间点。

## 决策

2026-09-28 接受，排入 v0.1.8。
