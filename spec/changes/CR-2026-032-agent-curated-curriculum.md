# 变更摘要

对没有成型教材的方向，由 Agent 从学习目标出发草拟大纲、搜集资料、挂到节点上；学习者确认大纲后按正常流程学习。程序只负责存档、校验与“每个节点有没有来源”的检查。

## 动机

很多方向没有一本合适的教材，比如“向量数据库”“某个新框架”。学习者只能零散地问 AI，这正是本产品想解决的问题。

## 目标行为

- `learn curriculum add --goal "<学习目标>" --id <id>`：建立没有资料的课程，大纲状态为 draft。
- Skill 工作流：
  1. 了解学习者的已有基础与目标，草拟主题地图与前置知识；
  2. 学习者确认大纲（现有 confirm 流程）；
  3. 按节点搜集资料，优先官方文档、原始论文、知名教材与课程；抓取用 Agent 自己的搜索/抓取能力或 `learn source add <网址>`；
  4. `learn source attach` 挂到节点，每个节点至少一份资料；
  5. 学习中发现更好的资料时追加；大纲调整走 `curriculum outline` 并保留版本。
- 没有来源的节点由 Agent 自己讲解时，节点标 `sourced: false`；教材首页与 `learn next` 标注“这一节没有原始资料，内容为 AI 综合”。这类节点的概念不能提交教材要点。
- `learn source check` 报告无资料节点数；学习首页显示“N 个小节没有原始资料”。
- 程序不联网搜索，也不评判资料质量。

## 数据与兼容性影响

依赖 CR-2026-025、026、027、031；无额外存储格式。

## 风险

- Agent 找来低质量或错误资料。缓解：Skill 规定来源优先级，并要求在教材首页写明每份资料的出处，学习者可以替换。
- 大纲漂移。缓解：确认后才生效，修改保留版本。

## 验收条件

1. 从一个学习目标出发，真实 Agent 完成草拟、确认、搜集、挂载，`source check` 报告无资料节点为 0。
2. 无来源节点在首页与 `learn next` 有明确标注，提交教材要点被拒。
3. 核心验证场景在这样的课程上与普通教材表现一致。

## 决策

2026-09-28 接受，排入 v0.1.8。
