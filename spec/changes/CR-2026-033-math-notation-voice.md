# 变更摘要

对话里只用终端能直接读的数学符号，完整推导写进 Obsidian 能渲染的概念笔记。只改 Skill，不改程序。

## 动机

Codex、Claude 的终端不渲染 LaTeX，`\forall \varepsilon > 0, \exists N` 这类源码很难读。数学分析这类课程几乎每轮都有公式。

## 目标行为

- 学习者可见话术规则：对话中用 Unicode 符号（ε、δ、∀、∃、→、≤、∑、∫、√、上下标如 xₙ、x²），不输出 `$…$` 或 `\command`；式子过长时分行写。
- 学习者手写笔记区域不受影响；程序生成的概念笔记与教材要点允许使用 `$…$`，Obsidian 负责渲染。
- 学习者自己用 LaTeX 提问时照常理解，回复仍用 Unicode 写法。

## 验收条件

1. 一段数学分析（ε-N 定义）的真实对话中没有 LaTeX 源码。
2. 同一概念的笔记中公式在 Obsidian 正常渲染。

## 决策

2026-09-28 接受，排入 v0.1.8。
