# 变更摘要

对学习者只呈现三段循环：① 资料搜集、② 学习、③ 巩固。其余机制（Learner Model、Learning Policy、解读记录）都是三段共用的幕后“记忆”。README、Vault 首页与产品规范按三段组织。

## 动机

现有功能按实现罗列：摸底、Session、Detour、复习、概念图谱、模式……学习者很难看出“我现在在做什么、下一步是什么”。

## 目标行为

| 阶段 | 包含 | 产出 |
| --- | --- | --- |
| ① 资料搜集 | 导入教材、确认大纲、资料接口（CR-025 至 031）、Agent 组织课程（CR-032） | 课程：大纲与挂在节点上的资料 |
| ② 学习 | 摸底、Session、教学策略、先修绕行、进度推进 | 原始对话与解读记录 |
| ③ 巩固 | 间隔复习、概念笔记、概念关系、学习模式 | 概念状态、笔记、知识图谱 |

- 两个循环：小循环 ② ⇄ ③（每天：学一节、巩固、到期复习）；大循环 ③ → ①（发现先修缺口或学完一本书，需要新资料）。
- `learn next` 的输出增加 `stage`（`collect`、`learn`、`consolidate`），由现有动作映射：`review_due`、`retrieval_probe` → consolidate；教材缺失、大纲未确认、全书学完 → collect；其余 → learn。映射是固定规则，不改变策略本身。
- Vault 首页按三段重排：“资料”（教材与大纲状态）、“学习”（正在学、下一步）、“巩固”（今天该复习、最近变化的概念）。
- README 与 `spec/product.md` 以三段循环作为主图，现有细节下沉为各阶段说明。

## 数据与兼容性影响

不改变存储格式。首页结构变化，重建后生效；`learn next` JSON 只新增字段。

## 验收条件

1. `learn next --json` 在复习到期、大纲未确认、正常学习三种情况下分别输出 consolidate、collect、learn。
2. 首页出现三段标题，原有信息都能在对应段找到。
3. README 首屏能看到三段循环图。

## 决策

2026-09-28 接受，排入 v0.1.8。
