# 变更摘要

规定每类笔记之间用什么链接、链接多少条，使知识层的边只表达知识关系，证据与导航链接数量受控并可被 CR-2026-035 的标签筛掉。

## 目标行为

| 从 → 到 | 规则 |
| --- | --- |
| 概念 → 概念 | 双链，表达概念关系（类型见 CR-2026-037） |
| 概念 ↔ 问题 | 问题笔记链接到它的概念；概念笔记列出问题时也链接 |
| 概念 → 原始对话 | 保留可点回原话的能力，但**每个学习记录只链接一次**：原话按 Session 分组，每组一个链接，组内原话以普通文字列出并注明轮次 |
| 概念 → 学习记录 | 修订历史表中的 Session 改为普通文字（日期），不再链接；需要时从证据链接跳转 |
| 概念 → 教材首页 | 改为普通文字加标签 `learning/curriculum/<id>`，不再链接，避免教材首页成为中心 |
| 学习记录 → 概念 | 保留链接（历史层，默认筛掉） |
| 首页、总览、教材页 → 概念 | 保留链接（导航层，默认筛掉） |

- 误解、认知变化、教学策略不成为独立节点，留在概念笔记内。
- 图谱默认节点为“概念 + 问题 + 手写笔记”（由 CR-2026-035 的默认筛选决定）；学习者可加 `-tag:#learning/knowledge/question` 只看概念。

## 数据与兼容性影响

只改投影；重建后生效，记录与原始对话不变。

## 验收条件

1. 在 v0.1.6 测试 Vault 上重建后，概念笔记发往原始对话的链接数不超过其涉及的 Session 数。
2. 概念笔记中不再有指向 `Sessions/` 与教材首页的双链。
3. 每条原话仍能通过所在 Session 的链接定位到原轮次。

## 决策

2026-09-28 接受，排入 v0.1.8。

2026-09-28 实现：知识笔记（概念、问题）中原话按 Session 分组、每组一个链接，其余位置原话只写轮次不加链接；不再链接学习记录与教材首页。
