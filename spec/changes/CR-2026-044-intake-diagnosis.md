# 变更摘要

给出目标或教材后，先做一次“入学”摸底 Session：目标访谈加诊断题。评估结果携带目标卡与概念级的证据；程序把这些证据对应到大纲条目声明的概念上，Agent 据此少排或跳过已经掌握的内容。

## 动机

现在摸底发生在大纲写好之后，而且结果只用来定起点，不会反过来影响课程设计：摸底发现学习者已懂余弦相似度，大纲也不会变。评估结果中的“已有知识”“先修缺口”也只是文字，无法和大纲条目对上。

## 目标行为

- 摸底评估可在大纲确认前完成：没有已确认大纲时，`recommended_entry.node` 可以留空；确认大纲后再按评估设起点。
- 评估新增可选 `goal_card`（CR-2026-043 的结构），会话结束时写入目标卡。
- `existing_knowledge`、`prerequisite_gaps`、`possible_misconceptions` 的每一项可带 `concepts`（kebab-case 概念 ID），与大纲条目的 `concepts` 使用同一套 ID。
- 程序计算“条目证据提示”：对每个条目，列出其概念在最近评估中属于已有知识、先修缺口还是可能的误解，以及在 Learner Model 中的状态。用于：
  - 目标课程：Agent 草拟大纲时少排或标注已经掌握的内容；
  - 教材课程：Agent 据此提出 `skip` / `mark_known` 调整建议（CR-2026-041），由学习者决定。
- Skill 的建课顺序改为：目标访谈 → 诊断题 → 结束摸底（写入目标卡与概念证据）→ 草拟大纲 → 草案评审（CR-2026-045）→ 确认 → 挂资料。学习者要求跳过摸底时，仍需做简短的目标访谈并用 `goal set` 写入目标卡。

## 数据与兼容性影响

评估 JSON 新增可选字段；旧评估仍然有效。

## 验收条件

1. 没有已确认大纲时可以完成摸底，评估中的目标卡被写入课程。
2. 条目证据提示正确对应评估中的概念；没有评估时提示为空。
3. 教材课程摸底后，已有知识覆盖的条目出现在提示中，但大纲不被自动修改。

## 决策

2026-09-28 接受，排入 v0.2.1。
