# 变更摘要

新增 `learn vaults [目录] [--json]`：列出目录本身及其下两层中的学习库，每个库给出课程、当前课程、进行中的 Session 与今天到期的复习数。配合已有的全局参数 `--vault <路径>`，Agent 在一个存放多个学习库的总文件夹中启动时，可以先找到库，再对指定库的课程操作。

## 动机

学习者想用一个总文件夹管理多个学习库（例如工作、数学、语言各一个）。`learn` 已经可以用 `--vault` 指定任意学习库，但 Agent 不知道总文件夹下有哪些库，只能自己翻目录猜。

## 目标行为

- `learn vaults [目录]`：缺省为当前目录；识别方式与 `learn` 查找学习库相同（`.learning/schema-version`）；扫描目录本身与其下两层，跳过隐藏目录，不进入学习库内部继续查找。
- 每个库输出：路径、名称（文件夹名）、界面语言、当前课程、课程列表（ID、标题、类型、资料种类、目录状态、完成与总小节数）、是否有进行中的 Session（种类与课程）、今天到期的复习数。
- 某个库读取失败时，该库带 `error` 字段列出，其余照常输出。
- 只读，不修改任何文件。

## 不在本变更

总文件夹的 `AGENTS.md`、跨库的汇总与今日安排（学习者决定暂不做）。

## 验收条件

1. 一个目录下的两个学习库（一个在下两层）都被列出，内容正确；学习库内部不会被当成新的库。
2. 目录本身就是学习库时也被列出。
3. 损坏的库带错误信息，不影响其他库。
