# v0.1.1 需求基线

**状态：** implemented  
**冻结日期：** 2026-09-24

## 核心目标

让 Learning OS 从“记录学习对话”前进到“先识别学习者，再按证据教学”。默认教学策略为 Guided Socratic Policy，首次进入 Curriculum 必须建议 Baseline Assessment。

## 必须交付

- Session kind：`baseline`、`lesson`、`review`、`practice`。
- Baseline depth：`quick`、`standard`、`deep`。
- active curriculum 没有 baseline 时，`session start` 默认创建 baseline。
- 明确开始 lesson 且没有 baseline 时，需要显式 `--skip-baseline`，并留下记录。
- baseline 活动期间，Runtime 拒绝 Curriculum Position 更新。
- baseline end 必须接收结构化 Assessment，校验证据来自 Raw Conversation，再写入 Profile。
- `status --json` 显示 baseline 状态和 active session kind。
- Agent Skill 实施摸底、Guided Socratic、Vocabulary Budget、prerequisite detour 和 return point。
- 常规 Runtime 记录在学习期间静默执行，不把内部工具操作混入课程对话。
- 提供显式 Agent 资产升级命令；升级前 dry-run，正式更新时备份已有文件。

## 教学约束

- Standard baseline 默认 5–8 个问题，一次一个。
- 摸底问题先用具体场景，不在问题中泄露答案。
- Lesson 每轮默认最多引入两个未建立的新术语。
- 仅识别或复述不能证明掌握；至少需要解释或预测证据。
- solid 需要延迟检索或迁移证据。
- 缺少基础术语时使用最小直接解释，再恢复苏格拉底式探究。

## 不包含

- 网络 Model Provider。
- 自动生成完整教材题库。
- 数值化 mastery score。
- 自动间隔重复调度。

## 验收场景

1. 新 Curriculum 的无参数 session start 产生 standard baseline。
2. baseline 期间 position set 被拒绝且文件不变。
3. baseline 缺少结构化 Assessment 时不能正常 end。
4. Assessment 引用不存在于 Conversation 的证据时被拒绝。
5. 合法 Assessment 生成用户可读 Markdown，并使 status 显示 assessed。
6. assessed Curriculum 的无参数 session start 产生 lesson。
7. 未 assessed Curriculum 只有显式 skip 才能直接 lesson。
8. Agent 资产升级 dry-run 零写入，正式更新保留备份。
9. v0.1 Vault 无需手工编辑即可升级并继续读取既有 Session。
10. 普通教学回合直接承接学习内容，不播报 status、append、position 或 Session 保存动作。
