# v0.1.2 需求基线

**状态：** implemented  
**冻结日期：** 2026-09-24  
**来源：** [CR-2026-004](../changes/CR-2026-004-evidence-derived-learner-model.md)

## 核心目标

第一次完成产品核心闭环：学习对话经 Runtime 校验成为可追溯的 Interpretation Record，回放形成 Learner Model 与 Cognitive History，再由确定性 Learning Policy 选出带历史证据、且不偏离教材主线的下一步教学动作。

## 必须交付

- 稳定 turn ID 与块锚点，旧 Conversation 按序号兼容。
- `session append --json`、`session turns`。
- Interpretation Record 校验与持久化：`session checkpoint`、`session end --analysis-file`、`session annotate`。
- Concept 身份与去重、Learning Event、Cognitive Change、State Update、Strategy Attempt、Pattern Observation、Retraction、Progress Decision。
- 从记录回放派生 Learner Model；`model rebuild`。
- Detour 命令与 Detour 日志。
- `learn next` 确定性 Learning Policy 与策略选择。
- `state` 与 `state concept` 读取 Learner Model。
- 最小 Markdown 投影：Concept、Session、Learner overview、Curriculum index，保护用户手写区。
- Agent Skill 升级：提交记录、checkpoint 时机、读取 `learn next`、`solid` 改为 `stable`。
- 12 Session 回放验收夹具。

详细格式与规则见 [Interpretation Record 规范](../interpretation-record.md) 与 [CLI 契约](../cli.md)。

## 不包含

- 网络 Model Provider 或自动推断；解释由 Agent 提交，Runtime 只校验和派生。
- 独立的 Questions、Hypotheses、Misconceptions、Insights 文件。
- Knowledge Graph 可视化、Dashboard、OCR、PDF 正文提取、自动复习调度、数值化掌握分数。
- Source 删除、归档与恢复（CR-2026-001 余下部分）。
- `.learning/state.json` schema 升级。

## 验收场景

1. 新写入的 Conversation 条目带 turn ID 与块锚点；旧格式 Conversation 仍能列出 turn。
2. 引用助手 turn、不存在 turn 或与原文不符的 quote 的记录被拒绝，且模型与投影不变。
3. 仅 `recognized` 证据不能产生 `developing`；缺少跨 Session retrieval 或 transfer 证据不能产生 `stable`。
4. 包含理解修正的 checkpoint 生成 Cognitive Change、受影响 Concept 投影与 Session 投影。
5. 后续反例把 `stable` 修订为 `fragile`，Concept 投影保留完整修订历史。
6. 重复提交同一记录返回 `unchanged`；同 ID 不同内容被拒绝。
7. 删除 `learner-model.json`、学习者总览与教材首页后，`model rebuild` 得到逐字一致的结果；Concept 与 Session 中的用户手写区保持不变。Session 文件头由 Session 生命周期写入，重建只刷新其中的分析区块。
8. lesson 结束时缺少分析且未声明 `--no-analysis` 被拒绝。
9. Detour start 与 end 完整记录原因、返回条件、所学内容和 return point，并恢复原位置。
10. 同一 Concept 连续 2 次 ineffective 的策略不会被 `learn next` 再次选中；换策略时派生 `strategy_switch`。
11. Pattern 只有在 2 个 Curriculum、2 个 Session 的支持下才成为 `supported`，反例保留在投影中。
12. 回放验收：12 Session 历史使 `learn next` 的动作或策略不同于无历史对照组，`history_used: true`，并引用至少 2 个更早 Session 的证据，且未越出当前章节或已记录 Detour。
13. v0.1.1 Vault 无需手工编辑即可使用全部 v0.1.2 命令，`agent update` 能升级 Skill。
