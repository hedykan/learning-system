**状态：** accepted，尚未开始开发

## 不在本版

- PDF 按页读取文字（IDEA-015，仍暂缓）。
- 视频字幕自动获取、语音识别。
- 需要登录的在线文档（Notion、Google Docs 等）。

## 验收

以各变更单验收条件为准；发布前按 [核心验证场景](../validation-scenarios.md) 做真实 Agent 复验，并至少在一门“教材 + 外部视频”课程和一门 EPUB 或网址课程上各学完一节。
