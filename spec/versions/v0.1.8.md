# v0.1.8 需求基线

**状态：** accepted，尚未开始开发  
**冻结日期：** 2026-09-28

主题：三段式学习流程、图谱整理与资料接口地基。学习者只面对“资料搜集 → 学习 → 巩固”三段；知识图谱只表达知识；所有资料通过同一组适配器接口进出。

## 不在本版

- 文字类格式、代码项目、网址快照：见 [v0.1.9](./v0.1.9.md)。
- Agent 搜集资料组织课程：见 [v0.2](./v0.2.md)。
- PDF 按页读取文字（IDEA-015，仍暂缓）。
- 视频字幕自动获取、语音识别。
- 需要登录的在线文档（Notion、Google Docs 等）。

## 验收

以各变更单验收条件为准；发布前按 [核心验证场景](../validation-scenarios.md) 做真实 Agent 复验，并至少在一门“教材 + 外部视频”课程上学完一节，在 Obsidian 中用默认筛选检查图谱。
