# v0.1 需求基线

**状态：** implemented  
**冻结日期：** 2026-09-24

## 范围

### 安装与初始化

- 可通过 `go install ./cmd/learn` 安装。
- 提供 `learn version`、`init`、`status`。
- 初始化完整 Vault、schema version 1 和 Git。
- Rules、Skills 和 references 内嵌二进制并由 init 生成。
- 重复初始化保留用户已有文件。

### 教材管理

- 支持导入单个 Markdown、Text、PDF 文件或 Markdown/Text 目录。
- 支持 copy 和 link；copy 为默认。
- 支持 dry-run、JSON 输出、哈希去重、显式确认和激活。
- 支持 list、show、activate、position 查询与设置。
- PDF v0.1 只保存/登记原件和元数据，不承诺正文提取。

### 学习会话

- 支持 start、append、end。
- Conversation append-only。
- end 生成 Session Markdown、保守的事件与认知变化占位结果，并更新 last session。
- 为 Provider 抽象和 FakeProvider 留出稳定接口；v0.1 不要求真实网络模型。

### 状态与 Git

- `state` 和 `curriculum` 可读展示并支持 JSON。
- 成功初始化 Git；成功结束 Session 后尝试提交。
- Git 失败不破坏数据。

### Agent 使用

- Codex 和 Claude 在 Vault 根目录可发现操作说明。
- Skill 指导 Agent 先查询状态、dry-run 导入、显式记录每轮对话并结束 Session。
- CLI 不声称能够自动读取宿主私有聊天历史。

## 验收场景

1. 空目录初始化后结构完整，第二次初始化无覆盖。
2. 在 Vault 子目录执行 status 能发现根目录。
3. Agent 可 dry-run 后导入教材并激活，状态显示当前教材。
4. 同一教材重复导入被识别，不覆盖原件。
5. start → append user/assistant → end 后产生 Conversation 和 Session，active session 清空。
6. Conversation 已有内容不能通过普通命令修改，只能追加。
7. 关键写入失败时既有状态保持可读。
8. `go test ./...`、`go test -race ./...`、`go vet ./...` 和四目标交叉构建通过。

## 发布门槛

- 所有验收场景有自动测试或明确的发布检查。
- README 覆盖安装、快速开始、教材导入和 Agent 学习流程。
- 不包含未通过变更流程进入 v0.1 的能力。
