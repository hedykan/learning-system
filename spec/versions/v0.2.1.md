# v0.2.1 需求基线

**状态：** accepted，尚未开始开发  
**冻结日期：** 2026-09-28

主题：入学。给出目标或教材后，先通过目标访谈与诊断摸底了解学习者，再据此设计课程、逐节评审、有理由地挑选资料。

```text
给目标 / 教材
    ↓
① 目标访谈 → 目标卡
    ↓
② 诊断摸底 → 概念级证据
    ↓
③ 草拟课程（目标卡 + 证据）
    ↓
④ 草案评审（覆盖检查）→ 确认 → 挂资料（附理由）
```
