# v0.2 需求基线（草案）

**状态：** proposed，范围待定  
**起草日期：** 2026-09-28

主题：Curriculum Builder。v0.1 系列解决“跟着一份资料怎样真正学会”（Learning Loop）；v0.2 让课程本身成为可构建、有来源、会随学习者演化的对象（Curriculum Loop）。Learner Model、证据校验与复习机制沿用 v0.1，不推倒重来。

设计输入：[Curriculum Builder 核心想法](../proposals/curriculum-builder.md)。

## 候选内容

| 内容 | 来源 |
| --- | --- |
| 课程类型 Source-aligned / Synthesized，类型决定谁能改什么 | Curriculum Builder §2 |
| Topic 元数据：why、prerequisites、sources、sourced；程序校验先修存在且无环，`learn next` 只推荐先修已完成的节点 | Curriculum Builder §2、讨论记录 2 |
| Agent 搜集资料、组织课程 | [CR-2026-032](../changes/CR-2026-032-agent-curated-curriculum.md)（待重写） |
| 有证据、有版本的课程调整：Agent 提交调整建议，学习者确认后生效 | 讨论记录 3 |
| 跨课程复用已学概念：其他教材中已 stable 的概念改为快速检索验证 | 讨论记录 4 |

## 范围原则

第一版只做“学习目标 → 大纲 → 挂资料 → 学”；课程自动调整放在后续小版本。进入开发前须将上表各项写成变更单并评审。
