# v0.2 需求基线

**状态：** implemented  
**冻结日期：** 2026-09-28

主题：Curriculum Builder。v0.1 系列解决“跟着一份资料怎样真正学会”（Learning Loop）；v0.2 让课程本身成为可构建、有来源、会随学习者演化的对象（Curriculum Loop）。Learner Model、证据校验与复习机制沿用 v0.1。

设计输入：[Curriculum Builder 核心想法](../proposals/curriculum-builder.md)。

## 范围原则

- 课程的任何调整都需要学习者同意；程序不自动改大纲（讨论记录第 5 点的待定项按“必须确认”落实）。
- 程序不联网搜索、不评判资料质量；研究由 Agent 完成。

## 验收

以各变更单验收条件为准；发布前按 [核心验证场景](../validation-scenarios.md) 做真实 Agent 复验，并从一个学习目标出发完成研究、建纲、挂资料并学完一节，过程中至少触发一次课程调整建议。
